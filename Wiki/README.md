# Wiki 阅读与维护入口

从 [内容索引](index.md) 查找论文、主题、待解决问题和进度。Wiki 保存可回溯来源的整理成果，由 Codex 按 [内容约定](../Schema/conventions.md)、[工作流程](../Schema/workflows.md) 与 [质量标准](../Schema/quality.md) 更新。

| 子目录 | 内容 |
| --- | --- |
| `paper/` | 论文问题、方法、结论、证据与局限，明确来源阅读范围 |
| `benchmark/` | 按论文聚合的作者评测摘录，每行保留独立实验条件 |
| `topic/` | 围绕研究问题整合多篇论文的共识、分歧、条件差异和知识缺口 |
| `questions/` | 写入任务中遇到的证据缺口、影响、关联来源和解决证据 |
| `Progress/` | 用户计划、已完成工作及其产物证据、下一步；不覆盖 Raw 原始计划 |

写入前使用 [对应模板](../templates/README.md)。普通问答和健康检查默认不修改本目录或日志；只有明确入库、保存、修复或进度更新任务才产生对应写入。相关目录在首次写入时创建。
