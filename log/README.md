# 操作日志

[operations.md](operations.md) 按时间追加记录明确授权的入库、保存、修复、进度更新及规范维护。Git 保存文件差异；这里记录输入、知识变化的理由、实际产物、完成情况、检查结果与遗留问题。不要求每次操作自动执行 commit，也不复制完整 diff。

普通问答和只读健康检查不写日志。入库发现重复且无变化时，可以记录一次“跳过”及原因，不重写已有内容。既有日志不回写，后续更正追加新条目并引用旧条目。

记录格式与完成状态以 [内容约定](../Schema/conventions.md) 和 [工作流程](../Schema/workflows.md) 为准。时间使用 `Asia/Shanghai`；Git 提交号仅在确实存在时填写。
