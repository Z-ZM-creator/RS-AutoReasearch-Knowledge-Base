## 真实来源隔离演练

在独立验收目录复制本次规范及模板，实际读取两篇全文：[RAG 的 NeurIPS 2020 版本](https://papers.neurips.cc/paper/2020/file/6b493230205f780e1bc26945df7481e5-Paper.pdf) 和 [REALM 的 ICML/PMLR 2020 版本](https://proceedings.mlr.press/v119/guu20a/guu20a.pdf)。另以 [Atlas arXiv v3 的摘要](https://arxiv.org/abs/2208.03299v3) 检查只读摘要边界，并创建实际零字节来源检查阻塞处理。未运行论文代码或复现实验，未宣称读过独立补充材料。

| 场景 | 实际结果 |
| --- | --- |
| 正常全文入库 | 生成有证据定位的论文、评测与主题页，维护索引和日志；最小提取，不声称收录全部实验。 |
| 第二篇更新已有主题 | 更新同一主题的判断和适用范围，保留前后快照及原证据。 |
| 条件差异与评测比较 | 三行结果各保留独立配置；条件未对齐时并列展示，不据原始数值排名。 |
| 重复来源 | 复用原 ID，无新增页面或索引重写；哈希差分仅操作日志。 |
| 空来源 | 无身份时只记录阻塞问题，不创建虚构论文或评测。 |
| 仅摘要 | 生成有限论文页和待补全文问题，标记部分完成，不生成未读 benchmark。 |
| 普通问答 | 独立协作代理读取规范并回答；隔离根全部 34 个文件 SHA-256 前后相同，差分为 0。 |
| 明确保存 | 复用已有主题；差分恰为主题页、索引、操作日志三个文件。 |

八个场景通过。最终隔离夹具包含九个真实内容页，170 个实际本地链接的存在性与精确大小写检查通过；最终固定基线后 Raw 五个文件的哈希不变。关键表格已提取并渲染核对。曾发现夹具使用 `Raw/Paper`，已纠正为 `Raw/paper`，随后重新固定基线并重验问答、保存和最终路径。

这是代理按规范逐项执行并用哈希记录的流程演练；普通问答额外使用独立协作代理，不等同于产品自动化程序或 CLI 自动加载测试。根代理已复核问答、保存、去重、Raw 保护及静态检查的 JSON 结果。

## 指令加载结果与限制

应用内只读代理确认能沿外层入口主动读取实际项目规则，并准确识别四项边界。该观察只证明转发可执行，不证明独立 CLI 新会话自动发现已经通过。

独立 CLI 测试未确认：首次沙箱内模型端点连接被拒绝；使用当前配置时遇到 CLI 不支持 `ultra` 的解析错误；仅对一次命令覆盖为兼容的推理设置后，仍遇到模型元数据 `max` 不兼容及后续采样超时，已停止重试。未修改用户配置或切换模型。
